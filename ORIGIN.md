# Origin and preserved history

This repository is a GitHub fork of [`rancher/rancher-net`](https://github.com/rancher/rancher-net). The official upstream history is preserved through commit `721d6ddb2f0a4faa11c9a50e75ed28e1f7cad317`, the upstream `v0.11.2` boundary used for this migration.

PastureStack changes are recorded as one maintenance commit after that boundary. That commit preserves the functional Ubuntu 26.04 work, replaces personal publication locations with PastureStack resources, updates the runtime dependencies, and introduces the PastureStack public names. It does not claim authorship of upstream work and does not remove upstream copyright or license notices.

PastureStack is an independent community effort to preserve, audit, and modernize the Rancher 1.6 ecosystem. It is not affiliated with or endorsed by Rancher Labs or SUSE.
